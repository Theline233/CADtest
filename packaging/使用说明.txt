CAD 图纸复核工具

安装版：安装后从开始菜单启动。便携版：把整个 CadReview 文件夹解压到可写的本机目录，双击 CadReviewUI.exe。
请保留 runtime、work、templates 和 licenses 文件夹。程序自带运行时，正常识别和导出不要求另装 .NET、Python、Node 或 PowerShell 7。

1. 选择或拖入 DWG；多张图纸按可用资源并行处理。
2. 对照原图核对明细。软件不内嵌 CAD 看图，请自行使用 AutoCAD 或其他已安装的查看程序。
3. 双击字段修改；按 Esc 取消当前单元格编辑，不改变其决定。
4. 打 X 行默认不纳入；明确采用或提交修改时记录纳入操作，导出仍需确认。
5. 批量导出先勾选图纸，再选择文件夹，逐张核对确认。同批重名文件自动区分。

识别结果、复核存档和内部导出记录保存在本软件目录 outputs 中，原图副本位于 ui-inputs。
升级保留这两个目录。卸载默认保留数据；只有明确选择删除数据才移除它们。
旧任务绑定识别时的路径，不要随意移动已经有任务的安装目录。

数量、单位、工艺、父子计价范围仍需人工核对，程序不承诺所有图纸都正确识别。
只有主动使用图片 API 复查时才发送所选截图到自行配置的服务；可能计费。安装包不含 API 密钥。
生成 Excel 不需要安装 Excel；查看和编辑导出表请使用合适的表格软件。
