# CAD 图纸复核桌面程序

Windows WPF 前端，与仓库内的识别和复核后端一起构建。界面不显示 CAD 图面；需要核对时使用 AutoCAD 或系统已关联的查看程序打开原图。

## 启动

在仓库根目录执行：

~~~powershell
.\Build.ps1
.\Start.ps1
~~~

也可在构建后双击本目录 Start-CadReviewUI.cmd。需要 PowerShell 7、.NET 10 Desktop Runtime、Python 3.11+、Node.js 22+；构建需要 .NET 10 SDK。不依赖 Codex。环境配置与命令行用法见 [根目录说明](../README.md)。

默认从程序位置向上查找工作区，或使用绝对路径 CADTEST_ROOT。Python、Node 和 PowerShell 可分别用 CADTEST_PYTHON、CADTEST_NODE、CADTEST_POWERSHELL 指定；否则查找本项目运行时及系统 PATH。程序启动子进程时传递同一工作区和 UTF-8 编码。

## 日常流程

1. 选择或拖入一张或多张 DWG。工作区外的图纸经提示复制到 ui-inputs，原文件保持不动；多张独立排队或并行识别。
2. 在左侧选择已打开的图纸，中间核对明细，右侧查看来源和提示。双击单元格编辑，提交后保存；按 Esc 取消当前单元格编辑，不改变该单元格的决定。序号按当前筛选和排序显示，不写入导出。
3. 填写复核人，点击“确认并导出 Excel”。每张图仍要确认纳入/排除范围；缺项、数量异常、来源变化或未解决问题会阻止导出。

同图号可查看重复处、采用默认累加或按一处计。整框打 X 的行默认不纳入；按照已确认的交互规则，明确采用、修订或提交实际字段修改时可自动记录纳入操作，也可填写具体原因。操作记录不等于程序证明原图已核查，最终导出仍需使用者确认。

支持 Shift/Ctrl 多选；对已多选行修改处理方式时会批量应用。批量采用和排除不再二次确认；恢复待复核会清除修订值，仍需确认。

## 批量导出

点击“批量导出”，勾选本次需要导出的已打开图纸（默认不勾选），选择本机文件夹。程序逐张执行同一套校验和导出确认，同批重名文件加 (2)、(3) 等后缀。取消或失败的图纸跳过并汇总，未勾选的图纸不导出。已有目标文件要确认替换，并保留原文件备份。

导出采用内置的中韩文报价表样式，单价留空。发布模板清除了作者、旧保存路径和打印机专用元数据；原始单元格、公式和样式保持。内部复核记录、来源哈希和导出关联保留在工作区 outputs 中；用户日常使用所选位置的 Excel 即可。

## 保存与布局

复核记录位于 outputs/ui-sessions，原识别来源保持只读。程序定时保存已提交修改，也支持 Ctrl+S。切换任务复用已打开的任务对象，但保存和导出仍检查冲突及来源；损坏或被其他窗口修改的存档不能静默覆盖。

左侧栏、详情栏可以拖动改宽度，双击拖动条恢复默认；程序根据窗口可用宽度约束两栏，避免重启或缩小窗口后裁切内容。布局保存在会话目录 ui-layout.json。

不要在新旧程序中同时编辑同一任务。旧任务绑定原始绝对路径，不能通过随意搬动存档获得可迁移性；缺少旧版专用引擎时，应在原环境处理或重新识别，不降级绕过校验。

## 可选图片 API 复查

“设置”中可配置支持图像输入的 Responses 或兼容 Chat Completions 服务。只有主动测试连接或选择截图并点击发送时才联网；截图会发送给选定服务商，可能计费。服务兼容性、模型权限与数据处理规则由使用者确认。

密钥由当前 Windows 用户 DPAPI 加密，配置位于 outputs/api-provider-settings 的用户子目录。建议单独保存在 outputs/api-review-results，不自动写回 CAD 原值、复核决定或报价。不要把配置、截图、建议记录或密钥上传到 GitHub。更换服务地址/协议时不会自动复用原密钥。当前仅验证了本机模拟服务，不能视为真实供应商兼容性认证。

## 开发验证

可公开运行的集成检查使用合成数据，不需要客户图纸：

~~~powershell
.\Build.ps1 -IncludeTestTools
python -B tests\make_ui_fixtures.py outputs\new-ui-fixtures
~~~

生成的 ui-fixtures.json 列出三个合成 review 目录。以下程序开关的输出目录必须是工作区 outputs 下的新目录：

- --selftest REVIEW OUTPUT：存档、复核表、校验及通用导出。
- --ui-validation-test REVIEW OUTPUT：无效数量等界面保护。
- --interaction-test OUTPUT REVIEW1 REVIEW2 REVIEW3：多选、序号、缓存、批量选择和布局。
- --frontend-integration-test OUTPUT REVIEW1 REVIEW2 REVIEW3：真实 WPF 单元格提交/取消、栏宽恢复、实际批量导出和取消确认。
- --api-selftest OUTPUT：合成图片及本机模拟 API，不调用真实服务。
- --recognize-test LOG OUTPUT DWG：通过界面同用的引擎入口识别本机图纸。

合成测试对话框使用预设答案和独立存档，不替用户核查真实图纸。发布前还需按实际使用环境检查原生文件对话框、鼠标拖选及打印效果。
